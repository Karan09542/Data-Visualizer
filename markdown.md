# 🌌 Interactive Visual Code Workspace & Node Playground

Welcome to the **Interactive Visual Code Workspace**, a high-performance visual tree visualizer, developer playground, and graph-based execution environment. It seamlessly combines rich hierarchical data structures (JSON, YAML, CSV) with fully sandboxed, live code execution nodes (Python & JavaScript/TypeScript) on an interactive, infinite-canvas layout.

This document outlines the elite features, advanced architecture, and visual design patterns built into the application.

---

## 🚀 Core Architectural Philosophy

Most data visualizers are static. This workspace transforms data into **living logical nodes** that can be edited, queried, connected, and executed in real-time. By utilizing isolated execution threads, custom sandboxing, and web-driver shims, it delivers a secure, responsive, and robust coding sandbox directly inside your browser.

---

## 🧩 Multi-Node Sandbox System

The heart of the workspace contains four specialized interactive node categories:

### 1. 🐍 Python Execution Nodes (Powered by Pyodide)
Python nodes run genuine Python code directly inside isolated background **Web Workers** for maximum thread safety and thread isolation.
*   **Web Worker DOM & Download Shim**: Normally, Web Workers lack access to the browser's Document Object Model (`document`, `window`). We engineered a custom virtual DOM proxy in `pyWorker.ts`. When a user runs Pyodide script like:
    ```python
    from js import Blob, document, window
    # ... create Blob & download element dynamically
    link_element = document.createElement("a")
    link_element.href = download_url
    link_element.download = "data_report.jpg"
    link_element.click()
    ```
    The virtual `document` element intercepts the `.click()` event and passes a message across the worker boundary, prompting the main thread to compile and trigger a native browser-side download automatically.
*   **Intelligent Package Resolution**: Integrates with `micropip` to capture imported Python modules. Any custom package (e.g., `requests`, `numpy`, `sympy`, etc.) is analyzed on-the-fly.
*   **PyMissingPromptModal**: Combines auto-detection with a clean interactive modal to let users selectively download missing libraries dynamically into their indexed virtual environment.
*   **Matplotlib Support**: Catch graphics and charts generated by Python libraries and render them nicely directly inline with the execution outputs.

### 2. ⚡ JavaScript & TypeScript Nodes
*   **Dynamic Sandboxing**: Write scripts to manipulate and transform JSON trees, execute canvas operations, or structure complex logical configurations.
*   **Isolated Logging Console**: Standard terminal inputs are fully captured in live terminal outputs specific to each JS/TS script run, preventing background pollution.
*   **Auto-Expansion & Focus**: Executing scripts automatically focuses the target Node Terminal and brings out the workspace visualizer console.

### 3. 🌐 API Sandbox Nodes
*   **Inline URL Editor**: Rapidly adjust endpoints with live editing elements.
*   **Schema Visualizer**: Query any public or custom API endpoint, fetch JSON payloads, and automatically map their key-value schemas onto the interactive visual graph.

### 4. 🗄️ JSON & YAML Primitives
*   Interactive tree viewing with deep nesting support.
*   Add, edit, or delete keys securely using standard in-app context menus.

## 🎨 Immersive Canvas & Interactive Engine

The layout leverages advanced vector mechanics to deliver a super-fluid user experience:
*   **Interactive Pan & Zoom**: Move effortlessly across large code trees and logical configurations.
*   **Reactive Edges (RenderEdge)**: Render active dependency lines between child properties, API requests, and execution outputs, making parent-child relationships simple to track.
*   **Drawing & Annotation Toolbar**: Allows quick spatial design markup directly on top of the nodes. Draw vectors, write text notes, highlight fields, and tag components.
*   **GUI Editor Panel**: Update style properties, change layout alignments, select custom themes, or switch structures on-the-fly.

## 📊 Comprehensive Data Renderers & Visualizers

The visualizer includes high-fidelity component integrations to serve diverse media:
*   **CSV & Table Grid Views**: Open CSV datasets in a fully paginated, sortable, and filterable spreadsheet view with rich custom cell layouts.
*   **Audio, Video, and Image Renderers**: Auto-detect raw data URLs and media schemes to serve fast previews without leaving the workspace.
*   **PDF Viewports**: Scroll, read, and inspect PDF documents.
*   **3D Model Visualizer**: Support for loading and interacting with standard 3D asset frameworks securely inside sandboxed iframes.

## 🛠️ User Workflow & Shortcuts

*   **Keyboard Navigation & Shortcuts**: Speed up operations with rapid hotkey combinations (available natively with a quick keybinding helper panel).
*   **Smart Workspace Tabs**: Tab views track active open files, edit states, and whether a tab contains a modified preview target.
*   **Responsive Collapsible File Explorer**: Organizes folders dynamically. Selecting any file anywhere in the canvas or tabs automatically expands containing parent folders to maintain strict visual parity.
*   **Auto-Saving**: Never lose progress—all code modifications, logical canvas layouts, and drawings are automatically saved to browser storage.

---

### 🛡️ Secure Sandbox Frameworks
1.  **Isolation**: Python code, packages, and custom scripts are executed inside isolated workers with timeouts, preventing long-running scripts from freezing the main UI thread.
2.  **No Key Exposure**: API queries are designed serverless-friendly, proxying endpoints safely where needed.
3.  **Cross-Origin Safety**: Previews are strictly contained within `SafeIframe` containers with locked runtime attributes to prevent security escapes.
